# NGO Impact CRM

## Multi-Tenant Social-Impact CRM with Donor Intelligence and Outcome Dashboards

A real-world NGO management platform designed to help NGOs manage donors, donations, campaigns, programmes, beneficiaries, receipts, reports, and social-impact information in one centralized platform.

## Project Status

🚧 Under Development

## Main Areas

- NGO Management
- Donor Management
- Donation Management
- Campaign Management
- Receipt Generation
- Programme Management
- Beneficiary Management
- Impact Dashboard
- Reports
- Donor Intelligence
- Audit Logs

## Technology

- Frontend: React
- Backend: Java + Spring Boot
- Database: PostgreSQL
- API: REST
- Version Control: Git + GitHub
- Containerization: Docker

## Important Note

The final requirements will be refined after real-world problem discovery and discussion with an NGO.
